# 3Sum (LeetCode 15)

## Problem Summary
Given an integer array `nums`, return all the triplets `[nums[i], nums[j], nums[k]]` such that `i != j`, `i != k`, and `j != k`, and `nums[i] + nums[j] + nums[k] == 0`.

Notice that the solution set must **not contain duplicate triplets**.

---

## 1. Bugs in Your Updated Code

### Bug 1: `break` instead of `continue` for outer loop `i`
```cpp
if (i > 0 && nums[i] == nums[i - 1]) {
    break; // ❌ CRITICAL BUG! Should be 'continue;'
}
```
- **Why it fails:** Using `break` terminates the entire outer loop as soon as `nums[i] == nums[i - 1]`.
- **Fix:** Use `continue;` so it only skips the current duplicate index `i` and proceeds to `i + 1`.

---

### Bug 2: Placing inner duplicate `while` loops outside the `else` block
```cpp
while (j < k) {
    int sum = nums[i] + nums[j] + nums[k];
    if (sum < 0) {
        j++;
    } else if (sum > 0) {
        k--;
    } else {                 
        ans.push_back({nums[i], nums[j], nums[k]});
        j++;
        k--;
    }
    // ❌ BUG: Placed outside the 'else' block!
    while (j < k && nums[j - 1] == nums[j]) j++;
    while (j < k && nums[k] == nums[k + 1]) k--;
}
```
- **Why it fails:** 
  1. The duplicate skip loops run on **every iteration**, even when `sum < 0` or `sum > 0`.
  2. If `sum > 0`, `k--` was executed, but `j` was NOT modified! Yet, `nums[j - 1] == nums[j]` is checked and can advance `j` prematurely.
- **Fix:** Move the inner `while` loops **INSIDE the `else` block** (only after a valid triplet is found and both `j++` and `k--` have been executed).

---

## 2. Correct & Optimal $O(n^2)$ Solution

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

class Solution {
public:
    vector<vector<int>> threeSum(vector<int>& nums) {
        vector<vector<int>> ans;
        int n = nums.size();
        
        // 1. Sort the array
        sort(nums.begin(), nums.end());

        for (int i = 0; i < n - 2; i++) {
            // Early Pruning: If smallest element > 0, sum can never be 0
            if (nums[i] > 0) break;

            // ✅ FIX 1: Skip duplicate outer elements using 'continue'
            if (i > 0 && nums[i] == nums[i - 1]) continue;

            int j = i + 1;
            int k = n - 1;

            while (j < k) {
                int sum = nums[i] + nums[j] + nums[k];

                if (sum < 0) {
                    j++;
                } else if (sum > 0) {
                    k--;
                } else {
                    // Found a valid triplet
                    ans.push_back({nums[i], nums[j], nums[k]});
                    j++;
                    k--;

                    // ✅ FIX 2: Skip duplicate inner elements INSIDE the 'else' block
                    while (j < k && nums[j] == nums[j - 1]) j++;
                    while (j < k && nums[k] == nums[k + 1]) k--;
                }
            }
        }

        return ans;
    }
};
```

---

## Complexity Analysis

- **Time Complexity:** $O(n^2)$ — Sorting takes $O(n \log n)$, and two-pointer search takes $O(n^2)$.
- **Space Complexity:** $O(1)$ auxiliary space (excluding the output array `ans`).

---

## Code

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

class Solution {
public:
    vector<vector<int>> threeSum(vector<int>& nums) {
        // Fast I/O
        ios_base::sync_with_stdio(false);
        cin.tie(NULL);

        vector<vector<int>> ans;
        int n = nums.size();

        sort(nums.begin(), nums.end());

        for (int i = 0; i < n - 2; i++) {
            if (nums[i] > 0) break;
            if (i > 0 && nums[i] == nums[i - 1]) continue;

            int j = i + 1;
            int k = n - 1;

            while (j < k) {
                int sum = nums[i] + nums[j] + nums[k];

                if (sum < 0) {
                    j++;
                } else if (sum > 0) {
                    k--;
                } else {
                    ans.push_back({nums[i], nums[j], nums[k]});
                    j++;
                    k--;

                    while (j < k && nums[j] == nums[j - 1]) j++;
                    while (j < k && nums[k] == nums[k + 1]) k--;
                }
            }
        }

        return ans;
    }
};

int main() {
    Solution sol;
    vector<int> nums1 = {-1, 0, 1, 2, -1, -4};
    vector<vector<int>> res1 = sol.threeSum(nums1);

    cout << "Test 1 Output:\n";
    for (const auto& triplet : res1) {
        cout << "[" << triplet[0] << ", " << triplet[1] << ", " << triplet[2] << "]\n";
    }

    return 0;
}
```
