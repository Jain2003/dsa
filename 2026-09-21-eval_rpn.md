# Evaluate Reverse Polish Notation (LeetCode 150)

## Problem Summary
You are given an array of strings `tokens` that represents an arithmetic expression in a **Reverse Polish Notation** (Postfix Notation).

Evaluate the expression. Return an integer that represents the value of the expression.

**Rules:**
- Valid operators are `+`, `-`, `*`, and `/`.
- Each operand may be an integer or another expression.
- Division between two integers always truncates toward zero.
- Guaranteed that the given RPN expression is always valid.

---

## 1. Solution & Logic Analysis

Your solution is **100% clean, correct, and optimal**!

### Key Mechanics:
- **Stack LIFO Behavior:** Numbers are pushed onto the stack. When an operator is encountered, the top two numbers are popped.
- **Operand Order:** 
  - `num1 = stx.top(); stx.pop();` (Right operand)
  - `num2 = stx.top(); stx.pop();` (Left operand)
  - Evaluates `num2 - num1` and `num2 / num1` correctly.

---

## Complexity Analysis

- **Time Complexity:** $O(N)$ — Single pass through `tokens` array of size $N$.
- **Space Complexity:** $O(N)$ — Auxiliary stack memory.

---

## Code

```cpp
#include <iostream>
#include <vector>
#include <string>
#include <stack>

using namespace std;

class Solution {
public:
    int evalRPN(vector<string>& tokens) {
        // Fast I/O
        ios_base::sync_with_stdio(false);
        cin.tie(NULL);

        stack<int> stx;

        for (auto x : tokens) {
            if (x == "+" || x == "-" || x == "*" || x == "/") {
                int num1 = stx.top();
                stx.pop();
                int num2 = stx.top();
                stx.pop();

                if (x == "+") {
                    stx.push(num2 + num1);
                } else if (x == "-") {
                    stx.push(num2 - num1);
                } else if (x == "*") {
                    stx.push(num2 * num1);
                } else {
                    stx.push(num2 / num1);
                }
            } else {
                stx.push(stoi(x));
            }
        }

        return stx.top();
    }
};

int main() {
    Solution sol;

    vector<string> tokens1 = {"2", "1", "+", "3", "*"};
    cout << "Test 1: " << sol.evalRPN(tokens1) << " (Expected: 9)" << endl;

    vector<string> tokens2 = {"4", "13", "5", "/", "+"};
    cout << "Test 2: " << sol.evalRPN(tokens2) << " (Expected: 6)" << endl;

    vector<string> tokens3 = {"10", "6", "9", "3", "+", "-11", "*", "/", "*", "17", "+", "5", "+"};
    cout << "Test 3: " << sol.evalRPN(tokens3) << " (Expected: 22)" << endl;

    return 0;
}
```
