# Two Sum (LeetCode 1)

## Problem Summary
Given an array of integers `nums` and an integer `target`, return indices of the two numbers such that they add up to `target`.

---

## 1. Brute Force Approach ($O(N^2)$ Time, $O(1)$ Space)
- Uses two nested loops to check every possible pair `(nums[i], nums[j])`.
- **Drawback:** Takes $O(N^2)$ time because for every element `nums[i]`, it scans the rest of the array linearly to find `target - nums[i]`.

---

## 2. Optimized Approach: Hash Map ($O(N)$ Time, $O(N)$ Space)

### Intuition:
Instead of using an inner loop to search for `moreNeeded = target - nums[i]`, we store each visited number and its index in a **Hash Map** (`unordered_map<int, int>`).
- Hash map lookup takes **$O(1)$ average time**.
- As we iterate through the array, we check if `moreNeeded` is already stored in our hash map.
- If it is found, we return `{mp[moreNeeded], i}` immediately!
- If not, we insert `mp[nums[i]] = i` and continue.

### One-Pass Algorithm Trace for `nums = [2, 7, 11, 15]`, `target = 9`:
1. `i = 0`, `current = 2`:
   - `moreNeeded = 9 - 2 = 7`.
   - `mp` is empty $\rightarrow$ `7` not found.
   - Store `mp[2] = 0`.
2. `i = 1`, `current = 7`:
   - `moreNeeded = 9 - 7 = 2`.
   - `mp` contains `2` (at index `0`).
   - Match found! Return `{mp[2], 1}` $\rightarrow$ **`{0, 1}`**.

---

## 3. Alternative Approach: Sorting + Two Pointers ($O(N \log N)$ Time, $O(N)$ Space)
- Store `pair<value, original_index>`.
- Sort the array of pairs by value in $O(N \log N)$ time.
- Place `left = 0` and `right = n - 1`:
  - `sum = pairs[left].first + pairs[right].first`
  - If `sum == target`: return `{pairs[left].second, pairs[right].second}`.
  - If `sum < target`: `left++` (increase sum).
  - If `sum > target`: `right--` (decrease sum).

---

## 4. How the One-Pass Hash Map Handles Duplicates (e.g. `nums = [3, 3]`, `target = 6`)

The One-Pass Hash Map handles duplicates **automatically and flawlessly**.

### Trace for `nums = [3, 3]`, `target = 6`:
1. `i = 0`, `current = 3`:
   - `moreNeeded = 6 - 3 = 3`.
   - Is `3` in `mp`? **No** (`mp` is empty).
   - Store `mp[3] = 0`.
2. `i = 1`, `current = 3`:
   - `moreNeeded = 6 - 3 = 3`.
   - Is `3` in `mp`? **YES!** (The first `3` at index `0` is already in `mp`).
   - Match found! Return `{mp[3], 1}` $\rightarrow$ **`{0, 1}`**.

### Why it works:
Because we check `mp.find(moreNeeded)` **BEFORE** inserting the current element into `mp`, the second instance of a duplicate number immediately finds the first instance already sitting in the hash map!

---

## Complexity Comparison

| Approach | Time Complexity | Auxiliary Space | Best Used When |
| :--- | :--- | :--- | :--- |
| **Brute Force** | $O(N^2)$ | $O(1)$ | Simple baseline, small inputs ($N \le 100$). |
| **Hash Map (One-Pass)** | **$O(N)$** (Average) | **$O(N)$** | Best general solution (LeetCode 1). |
| **Sorting + Two-Pointers** | $O(N \log N)$ | $O(N)$ | Array is already sorted or returning boolean `exists`. |

## Code

```cpp
#include <iostream>
#include <vector>
#include <unordered_map>
#include <algorithm>

using namespace std;

class Solution {
public:
    // Approach 1: Hash Map (One-Pass)
    // Time Complexity: O(N) average, Space Complexity: O(N)
    vector<int> twoSumHashMap(vector<int>& nums, int target) {
        ios_base::sync_with_stdio(false);
        cin.tie(NULL);

        unordered_map<int, int> mp; // Maps value -> original index

        for (int i = 0; i < nums.size(); i++) {
            int current = nums[i];
            int moreNeeded = target - current;

            if (mp.find(moreNeeded) != mp.end()) {
                return {mp[moreNeeded], i};
            }

            mp[current] = i;
        }

        return {};
    }

    // Approach 2: Sorting + Two-Pointer Approach (No Hash Map / No STL map)
    // Time Complexity: O(N log N) due to sorting, Space Complexity: O(N)
    vector<int> twoSumSorting(vector<int>& nums, int target) {
        int n = nums.size();
        vector<pair<int, int>> pairs(n);

        // Store pair of (value, original_index)
        for (int i = 0; i < n; i++) {
            pairs[i] = {nums[i], i};
        }

        // Sort by value: O(N log N)
        sort(pairs.begin(), pairs.end());

        // Two-Pointer scan: O(N)
        int left = 0;
        int right = n - 1;

        while (left < right) {
            int sum = pairs[left].first + pairs[right].first;

            if (sum == target) {
                return {pairs[left].second, pairs[right].second};
            } else if (sum < target) {
                left++; // Sum is too small, move left pointer right to increase sum
            } else {
                right--; // Sum is too large, move right pointer left to decrease sum
            }
        }

        return {};
    }
};

int main() {
    Solution sol;
    vector<int> nums = {2, 7, 11, 15};
    int target = 9;

    vector<int> res1 = sol.twoSumHashMap(nums, target);
    cout << "Hash Map Result: [" << res1[0] << ", " << res1[1] << "]" << endl;

    vector<int> res2 = sol.twoSumSorting(nums, target);
    cout << "Sorting + Two Pointers Result: [" << res2[0] << ", " << res2[1] << "]" << endl;

    return 0;
}
```
