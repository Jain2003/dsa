# Sqrt(x) (Binary Search)

## Problem Description
Given a non-negative integer `x`, return the square root of `x` rounded down to the nearest integer. The returned integer should be non-negative as well.

You must not use any built-in exponent function or operator, such as `pow(x, 0.5)` or `x ** 0.5`.

**Example 1:**
- **Input:** `x = 4`
- **Output:** `2`

**Example 2:**
- **Input:** `x = 8`
- **Output:** `2`
- **Explanation:** The square root of 8 is `2.82842...`, and since the part after the decimal point is truncated, `2` is returned.

---

## Bugs in User's Code

1. **Integer Overflow (`mid * mid`):**
   - For `x = 2147483647`, `mid` can be up to $46341$.
   - $46341 \times 46341 = 2147488281 > 2^{31} - 1$, causing 32-bit signed integer overflow (wrapping to a negative number).
   - **Fix:** Cast to `long long` (`(long long)mid * mid <= x`) or use division (`mid <= x / mid`).

2. **Inverted Logic (`mid * mid >= x`):**
   - Since we want $\lfloor \sqrt{x} \rfloor$, a candidate `mid` is valid if `mid * mid <= x`.
   - Checking `mid * mid >= x` incorrectly treats values where `mid * mid > x` as valid candidates.

3. **Returning `mid` instead of `ans`:**
   - Returning `mid` returns the last evaluated candidate rather than the maximum valid candidate `ans`.

---

## Optimal Approach: Binary Search

The square root of `x` lies in the search space `[1, x]`:
- If `(long long)mid * mid <= x`: `mid` is a valid answer! Store `ans = mid` and search right (`low = mid + 1`) for a larger valid integer.
- If `(long long)mid * mid > x`: `mid` is too large! Search left (`high = mid - 1`).

---

## Complexity Analysis

- **Time Complexity:** $\mathcal{O}(\log x)$ — Binary search halving range `1` to `x`.
- **Space Complexity:** $\mathcal{O}(1)$ auxiliary space.

---

## Code

```cpp
#include <iostream>

using namespace std;

class Solution {
public:
    int mySqrt(int x) {
        if (x == 0) return 0;

        int low = 1;
        int high = x;
        int ans = 0;

        while (low <= high) {
            int mid = low + (high - low) / 2;

            // Use long long to avoid integer overflow when squaring mid
            long long square = (long long)mid * mid;

            if (square <= x) {
                ans = mid;       // Valid floor square root candidate
                low = mid + 1;   // Try to find a larger valid candidate
            } else {
                high = mid - 1;  // Candidate is too large
            }
        }

        return ans;
    }
};

int main() {
    Solution sol;

    cout << "mySqrt(4): " << sol.mySqrt(4) << " (Expected: 2)\n";
    cout << "mySqrt(8): " << sol.mySqrt(8) << " (Expected: 2)\n";
    cout << "mySqrt(2147483647): " << sol.mySqrt(2147483647) << " (Expected: 46340)\n";

    return 0;
}
```
