# Pow(x, n) (Binary Exponentiation)

## Problem Description
Implement `pow(x, n)`, which calculates `x` raised to the power `n` ($x^n$).

**Constraints & Precision:**
- Answers within $10^{-5}$ of the actual value will be accepted.
- $-100.0 < x < 100.0$
- $-2^{31} \le n \le 2^{31} - 1$

---

## The Floating-Point Precision Trap (Why inverting `x` upfront fails)

### The Mistake:
```cpp
if (exp < 0) {
    x = 1.0 / x;   // ❌ FLOATING-POINT PRECISION BUG!
    exp = -exp;
}
```
When `x = -0.9999999968539456` and `n = -1669585506`:
1. Dividing `1.0 / x` upfront introduces an immediate microscopic floating-point rounding error in IEEE 754 64-bit double precision.
2. When this slightly inaccurate reciprocal base is multiplied over $1.66$ billion times, the rounding error **accumulates exponentially**!
3. The final result drifts by $0.000030$, exceeding LeetCode's strict $10^{-5}$ ($0.000010$) tolerance!

### The Solution: Invert at the END!
Calculate $x^{|n|}$ directly using the exact base $x$. Only perform the inversion **at the very end** on the final result:
```cpp
return (n < 0) ? (1.0 / ans) : ans; // ✅ Single division at the end maintains maximum precision!
```

---

## Mathematical Intuition: Why We Multiply `ans` Only When `exp` is Odd

### 1. The Recurrence Relation
For any base $x$ and integer exponent $n > 0$:

$$x^n = \begin{cases} (x^2)^{n / 2} & \text{if } n \text{ is even} \\ x \cdot (x^2)^{(n - 1) / 2} & \text{if } n \text{ is odd} \end{cases}$$

- **When $n$ is EVEN:** $x^n$ can be completely absorbed by squaring the base: $(x^2)^{n/2}$. There is **no leftover $x$** outside.
- **When $n$ is ODD:** There is **one leftover $x$** that cannot be paired up into $x^2$. That single leftover $x$ **must be extracted and accumulated into `ans`**!

### 2. The Binary (Bitwise) Representation Formula
Every integer $n$ can be expressed as a sum of powers of 2 (its binary representation):

$$n = \sum_{i=0}^{k} b_i \cdot 2^i \quad (b_i \in \{0, 1\})$$

Therefore, $x^n$ can be factored into a product of binary powers:

$$x^n = \prod_{i=0}^{k} \left(x^{2^i}\right)^{b_i}$$

- If bit $b_i = 1$ (which occurs when `exp % 2 == 1`), we multiply the current base term $x^{2^i}$ into `ans`.
- If bit $b_i = 0$ (when `exp` is even), $(x^{2^i})^0 = 1$, so we do **not** multiply into `ans`.

### 3. Step-by-Step Dry Run for $x = 2, n = 10$ ($10_{10} = 1010_2$)

| Iteration | `exp` at start | Parity | Action | `ans` after | `x` after | `exp` after |
| :---: | :---: | :---: | :--- | :---: | :---: | :---: |
| **Start** | 10 | - | Initial values | 1.0 | 2.0 | 10 |
| **1** | 10 | Even | Base squared | 1.0 | **4.0** ($2^2$) | **5** |
| **2** | 5 | **Odd** | Multiplied into `ans`: $1.0 \times 4.0$ | **4.0** | 4.0 | **4** (or $5/2=2$) |
| **3** | 4 (or 2) | Even | Base squared | 4.0 | **16.0** ($2^4$) | **2** |
| **4** | 2 | Even | Base squared | 4.0 | **256.0** ($2^8$) | **1** |
| **5** | 1 | **Odd** | Multiplied into `ans`: $4.0 \times 256.0$ | **1024.0** | 256.0 | **0** |

$$\text{Final Result} = 4 \times 256 = \mathbf{1024}$$

## Optimal C++ Implementation (Binary Exponentiation, $O(\log n)$ Time)


```cpp
#include <iostream>

using namespace std;

class Solution {
public:
    double myPow(double x, int n) {
        long long exp = n;
        if (exp < 0) {
            exp = -exp; // Only negate exponent, do NOT invert x here!
        }

        double ans = 1.0;

        while (exp > 0) {
            if (exp % 2 == 1) {
                ans *= x;
            }
            x *= x;
            exp /= 2;
        }

        // Invert at the very end to prevent exponential floating-point error accumulation
        return (n < 0) ? (1.0 / ans) : ans;
    }
};

int main() {
    Solution sol;

    cout << "Test 1: " << sol.myPow(2.0, 10) << " (Expected: 1024)\n";
    cout << "Test 2: " << sol.myPow(2.0, -2) << " (Expected: 0.25)\n";
    cout << "Test 3 (Edge Case): " << sol.myPow(-0.9999999968539456, -1669585506) << " (Expected: ~191.0637)\n";

    return 0;
}
```
