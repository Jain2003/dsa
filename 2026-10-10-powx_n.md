# Pow(x, n) (Binary Exponentiation)

## Problem Description
Implement `pow(x, n)`, which calculates `x` raised to the power `n` ($x^n$).

**Constraints & Precision:**
- Answers within $10^{-5}$ of the actual value will be accepted.
- $-100.0 < x < 100.0$
- $-2^{31} \le n \le 2^{31} - 1$

---

## The Floating-Point Precision Trap (Why inverting `x` upfront fails)

### The Mistake:
```cpp
if (exp < 0) {
    x = 1.0 / x;   // ❌ FLOATING-POINT PRECISION BUG!
    exp = -exp;
}
```
When `x = -0.9999999968539456` and `n = -1669585506`:
1. Dividing `1.0 / x` upfront introduces an immediate microscopic floating-point rounding error in IEEE 754 64-bit double precision.
2. When this slightly inaccurate reciprocal base is multiplied over $1.66$ billion times, the rounding error **accumulates exponentially**!
3. The final result drifts by $0.000030$, exceeding LeetCode's strict $10^{-5}$ ($0.000010$) tolerance!

### The Solution: Invert at the END!
Calculate $x^{|n|}$ directly using the exact base $x$. Only perform the inversion **at the very end** on the final result:
```cpp
return (n < 0) ? (1.0 / ans) : ans; // ✅ Single division at the end maintains maximum precision!
```

---

## Optimal C++ Implementation (Binary Exponentiation, $O(\log n)$ Time)

```cpp
#include <iostream>

using namespace std;

class Solution {
public:
    double myPow(double x, int n) {
        long long exp = n;
        if (exp < 0) {
            exp = -exp; // Only negate exponent, do NOT invert x here!
        }

        double ans = 1.0;

        while (exp > 0) {
            if (exp % 2 == 1) {
                ans *= x;
            }
            x *= x;
            exp /= 2;
        }

        // Invert at the very end to prevent exponential floating-point error accumulation
        return (n < 0) ? (1.0 / ans) : ans;
    }
};

int main() {
    Solution sol;

    cout << "Test 1: " << sol.myPow(2.0, 10) << " (Expected: 1024)\n";
    cout << "Test 2: " << sol.myPow(2.0, -2) << " (Expected: 0.25)\n";
    cout << "Test 3 (Edge Case): " << sol.myPow(-0.9999999968539456, -1669585506) << " (Expected: ~191.0637)\n";

    return 0;
}
```
