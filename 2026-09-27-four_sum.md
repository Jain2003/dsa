# 4Sum

## Problem Description
Given an array `nums` of `n` integers and an integer `target`, return an array of all the **unique** quadruplets `[nums[a], nums[b], nums[c], nums[d]]` such that:
- $0 \le a, b, c, d < n$
- $a, b, c,$ and $d$ are **distinct**.
- $\text{nums}[a] + \text{nums}[b] + \text{nums}[c] + \text{nums}[d] == \text{target}$

You may return the answer in any order.

**Example 1:**
- **Input:** `nums = [1,0,-1,0,-2,2]`, `target = 0`
- **Output:** `[[-2,-1,1,2],[-2,0,0,2],[-1,0,0,1]]`

**Example 2:**
- **Input:** `nums = [2,2,2,2,2]`, `target = 8`
- **Output:** `[[2,2,2,2]]`

---

## Approach & Key Insights

1. **Sorting First:**
   - Sorting simplifies duplicate handling and allows us to use two-pointer technique on the inner loops.

2. **Nested Loops + Two-Pointer Search:**
   - Fix index `i` from `0` to `n - 4`.
   - Fix index `j` from `i + 1` to `n - 3`.
   - Use two pointers `left = j + 1` and `right = n - 1` to search for:
     $$\text{nums}[i] + \text{nums}[j] + \text{nums}[left] + \text{nums}[right] == \text{target}$$

3. **Duplicate Prevention:**
   - **For `i`:** Skip if `i > 0 && nums[i - 1] == nums[i]`.
   - **For `j`:** Skip if `j > i + 1 && nums[j - 1] == nums[j]`.
   - **For `left` & `right`:** Once a valid quadruplet is found, skip duplicate values using `while` loops before moving `left++` and `right--`.

4. **Handling 64-bit Integer Overflow:**
   - Cast the sum calculation to `long long`:
     ```cpp
     long long currentSum = (long long)nums[i] + nums[j] + nums[left] + nums[right];
     ```

---

## Complexity Analysis

- **Time Complexity:** $\mathcal{O}(N^3)$ — Sorting takes $\mathcal{O}(N \log N)$ and two nested loops + two-pointer search take $\mathcal{O}(N^3)$.
- **Space Complexity:** $\mathcal{O}(1)$ auxiliary space (excluding space needed for the output vector).

## Code

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

class Solution {
public:
    vector<vector<int>> fourSum(vector<int>& nums, int target) {
        vector<vector<int>> ans;
        sort(nums.begin(), nums.end());
        int n = nums.size();
        int left = 0;
        int right = 0;
        
        for (int i{0}; i < n - 3; i++) {
            if (i > 0 && nums[i - 1] == nums[i]) {
                continue;
            }
            for (int j{i + 1}; j < n - 2; j++) {
                if (j > i + 1 && nums[j - 1] == nums[j]) {
                    continue;
                }
                left = j + 1;
                right = n - 1;
                while (left < right) {
                    long long currentSum = (long long)nums[i] + nums[j] + nums[left] + nums[right];
                    if (target == currentSum) {
                        ans.push_back({nums[i], nums[j], nums[left], nums[right]});

                        while (left < right && nums[left] == nums[left + 1]) {
                            left++;
                        }

                        while (left < right && nums[right] == nums[right - 1]) {
                            right--;
                        }
                        left++;
                        right--;
                        
                    } else if (currentSum > target) {
                        right--;
                    } else {
                        left++;
                    }
                }
            }
        }
        return ans;
    }
};

int main() {
    Solution sol;
    vector<int> nums = {1, 0, -1, 0, -2, 2};
    int target = 0;

    vector<vector<int>> result = sol.fourSum(nums, target);

    cout << "4Sum Quadruplets for target = " << target << ":\n";
    for (const auto& quad : result) {
        cout << "[ ";
        for (int x : quad) {
            cout << x << " ";
        }
        cout << "]\n";
    }

    return 0;
}
```
