# Subsets (Power Set / Backtracking)

## Problem Description
Given an integer array `nums` of unique elements, return **all possible subsets** (the power set).

The solution set must not contain duplicate subsets. Return the solution in any order.

**Example 1:**
- **Input:** `nums = [1, 2, 3]`
- **Output:** `[[], [1], [2], [1, 2], [3], [1, 3], [2, 3], [1, 2, 3]]`

**Example 2:**
- **Input:** `nums = [0]`
- **Output:** `[[], [0]]`

---

## 1. Bugs in Your Initial Code

1. **Compilation Errors:**
   - `n` was not defined (`nums.size()` needed).
   - Missing semicolon on `result.push_back(nums[i])`.
2. **Local `vector<int> result` bug:**
   - Declaring `vector<int> result;` fresh inside each function call means it was re-created empty every time, so it could only ever hold at most `1` element (`[nums[i]]`).
   - It could never accumulate multi-element subsets like `[1, 2]` or `[1, 2, 3]`.
3. **Missing the Empty Set (`[]`):**
   - The empty set `[]` is always a valid subset of every set.

---

## 2. Key Intuition: The "Include / Exclude" (Pick / Don't Pick) Pattern

For every element `nums[i]`, we have **2 choices**:
1. **Include `nums[i]`** in the current subset.
2. **Exclude `nums[i]`** from the current subset.

We maintain a `current` vector that tracks the subset being built:
- **Base Case:** When index `i == nums.size()`, we have made decisions for all elements. Add `current` to `ans`!

---

## 3. Decision Tree for `nums = [1, 2]`

```
                                      []  (i = 0)
                                    /    \
                       Include 1  /        \  Exclude 1
                                [1]          []  (i = 1)
                              /    \        /    \
                 Include 2  /       \     /        \ Exclude 2
                        [1, 2]      [1]  [2]       []  (i = 2, Base Case!)
```

Total Subsets = $2^N = 2^2 = 4$.

---

## Complexity Analysis

- **Time Complexity:** $\mathcal{O}(N \cdot 2^N)$
  - There are $2^N$ total subsets.
  - Copying each subset of average length $N/2$ into the result takes $\mathcal{O}(N)$.
- **Space Complexity:** $\mathcal{O}(N)$ auxiliary space for recursion stack depth and `current` vector.

---

## Code

```cpp
#include <iostream>
#include <vector>

using namespace std;

class Solution {
private:
    void helper(int i, vector<int>& nums, vector<int>& current, vector<vector<int>>& ans) {
        // Base Case: Decided for all elements
        if (i == nums.size()) {
            ans.push_back(current);
            return;
        }

        // Choice 1: Include nums[i]
        current.push_back(nums[i]);
        helper(i + 1, nums, current, ans);

        // Backtrack (Undo the choice)
        current.pop_back();

        // Choice 2: Exclude nums[i]
        helper(i + 1, nums, current, ans);
    }

public:
    vector<vector<int>> subsets(vector<int>& nums) {
        vector<vector<int>> ans;
        vector<int> current;
        helper(0, nums, current, ans);
        return ans;
    }
};

int main() {
    Solution sol;
    vector<int> nums = {1, 2, 3};

    vector<vector<int>> result = sol.subsets(nums);

    cout << "Total Subsets: " << result.size() << " (Expected: 8)\n";
    for (const auto& subset : result) {
        cout << "[ ";
        for (int x : subset) cout << x << " ";
        cout << "]\n";
    }

    return 0;
}
```
